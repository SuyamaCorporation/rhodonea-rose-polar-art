# ロドネアバラ曲線極座標アート

極座標 r=a·cos(kθ) で定義されるバラ型曲線（ロドネア）をブラウザ上でリアルタイム描画。花弁数kスライダー（整数・非整数対応）、色相グラデーション、描画アニメーション再生、PNG出力機能付き。

## 機能
- k値スライダー（1.0〜10.0、ステップ0.1）で花弁数を連続変化
- 整数k: k が奇数→k花弁、偶数→2k花弁として表示
- 振幅aスライダー（50〜280）で曲線の大きさを調整
- 開始色相スライダーで曲線に沿った色相グラデーションの起点を変更
- 線幅スライダー（1〜6）
- アニメーショントグルでkを連続変化させ花弁変形を演出
- 画面下部にk値と花弁数をリアルタイム表示
- PNG保存ボタンで画像出力
